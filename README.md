# KAEDE OS Installer

Official, minimal one-liner CLI installer for KAEDE OS.

## Quick Install

### Linux & macOS
```bash
curl -fsSL https://raw.githubusercontent.com/kaede-os/installer/main/installer.sh | bash
```
or via the documentation domain:
```bash
curl -fsSL https://kaede-os.github.io/installer.sh | bash
```

### Windows (PowerShell)
```powershell
iwr -Uri https://raw.githubusercontent.com/kaede-os/installer/main/installer.ps1 | iex
```
or via the documentation domain:
```powershell
iwr -Uri https://kaede-os.github.io/installer.ps1 | iex
```
